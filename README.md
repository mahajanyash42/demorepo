# Yash Rajesh Mahajan — portfolio

Three-page responsive portfolio for BUDT748. Built with semantic HTML, one shared CSS file, and Bootstrap 5.3.3 (navbar, grid, container, buttons, spacing utilities).

## Files
- `index.html` — Home
- `about.html` — About
- `contact.html` — Contact
- `css/styles.css` — custom visual style and mobile adjustments
- `design/` — Figma-importable layout guide
- `screenshots/` — page screenshots when generated

## Open locally
Open `index.html` with VS Code Live Server. Internet access is needed for Bootstrap and Google Fonts; system font fallbacks are supplied.

## Publish with GitHub Pages
Create a public GitHub repository, upload this folder's contents to its root, then select **Settings → Pages → Deploy from a branch → main / root**. The live link will have the form `https://USERNAME.github.io/REPOSITORY/`.

## Design in Figma
Create three desktop frames at 1440 px, add 12 columns with 80 px margins and 20 px gutters, then use `design/figma-guide.svg` as an importable composition reference. Recreate text, cards, and navigation as editable Figma layers before submitting a Figma design link. Export each finished frame as PNG for your own Figma evidence if required.
